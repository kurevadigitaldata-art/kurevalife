# KurevaLife

KurevaLife es el espacio digital de acompañamiento de Kureva, diseñado para ayudar a las personas a organizar información personal, reflexionar sobre sus necesidades y encontrar recursos útiles de forma clara, accesible y respetuosa.

La experiencia está pensada para acompañar, no para diagnosticar. KurevaLife no sustituye la atención médica ni ofrece recomendaciones de diagnóstico o tratamiento.

## Principios del proyecto

- Privacidad y tratamiento responsable de la información.
- Separación entre la experiencia pública de Kureva DigitalData y el espacio privado de KurevaLife.
- Accesibilidad, navegación sencilla y adaptación a dispositivos móviles.
- Respuestas y recursos orientados al acompañamiento, sin presentar la herramienta como profesional sanitario.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Verificaciones

```bash
pnpm check
pnpm build
```

Las verificaciones deben ejecutarse antes de considerar una publicación como validada. No se deben introducir claves privadas ni datos personales sensibles en el repositorio.

## Propiedad y configuración

El repositorio oficial de Kureva es administrado mediante la cuenta de GitHub vinculada a Kureva. Las credenciales, claves privadas y configuraciones sensibles deben mantenerse fuera del código público y gestionarse mediante variables de entorno o secretos del proveedor correspondiente.
